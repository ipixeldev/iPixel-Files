# iPixel-Files 1.1

## Complete Pixel mode and cross-container workflows

- Bundled the genuine **Press Start 2P** font and applied it across Pixel dashboard cards, tools, search, navigation and nested file views.
- Replaced SF Symbols on Pixel cards with crisp code-drawn 8×8 pixel glyphs; Blue and Lime retain normal system icons.
- Rebuilt Pixel folder stacks with hard stepped geometry and discrete frame animation.
- Added **Dual Browser**: side-by-side panes on iPad and retained Left/Right browsers on iPhone.
- Added a persistent **Transfer Shelf**. Long-press a file or folder, copy it to the shelf, open another app container and paste it there.
- Added safe cross-container copying, overlap/symlink protection, replacement confirmation and automatic backups before overwriting files.
- Added **Duplicate** and detailed **Info** actions.
- Retained dedicated sorting by Default, Name, Date, Type or Size in both directions.

The dual browser and transfer shelf are inspired by full file managers such as Filza, but use only WQFiles' non-jailbroken sandbox access. Root-only package installation, app uninstall, ownership changes and terminal execution are intentionally excluded.
