# iPixel-Files 1.0

## Pixel UI, themed icon and sorting

- Added **iPixel Pixel** as a third optional interface style with crisp geometry and pixel-style monospaced typography.
- Added a yellow/lime pixel-art alternate app icon that activates with **iPixel Lime**.
- Made every stacked-folder illustration and animation follow Blue, Lime or Pixel colors.
- Added a dedicated, always-visible sort control to file browsers.
- Added Default, Name, Date, Type and Size sorting with Ascending/Descending direction.
- Kept independent System, Light and Dark appearance choices for every interface style.

Designed and developed by **iPixelDev**. Based on [WQFiles](https://github.com/kolbicz/WQFiles) by **kolbicz**. Licensed under GPL-3.0-or-later.
