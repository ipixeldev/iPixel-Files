# iPixel-Files 1.6

## Clearer media browsing

- Replaced long generated media filenames with compact display labels such as **Video 2761**, while keeping the complete filename searchable and available in Info.
- Added explicit Video, Photo and Audio metadata plus matching fallback symbols.
- Added play, photo and waveform badges directly to generated thumbnails so the media type remains clear at a glance.
- Normalized thumbnails to square, edge-to-edge previews and enlarged them in both List and Grid views.
- Rebalanced Grid cards with more height, larger artwork, two-line titles, concise metadata and no table separators between cards.
- Removed custom close/share overlays that duplicated the native `AVPlayerViewController` controls.
- Audio files now use the same full-screen player with a dedicated waveform presentation and playback audio session.
- Added **Select Files** mode for choosing multiple regular files and opening one system share sheet, including AirDrop, sharing apps and Save to Files.
