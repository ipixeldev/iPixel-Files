# iPixel-Files 1.9

## A shorter Home and more Files-like workflows

- Moved the custom media Share button to the lower-left safe area so it no longer covers the native player close or AirPlay controls and does not sit over the timeline.
- Removed inline recent rows from Home. Recents now has its own compact screen with Recent Folders, Viewed Files, per-item removal and Clear All.
- Added an optional **Bottom navigation bar** switch under Appearance. It provides persistent Home, Apps, Starred, Recents and Search tabs and removes those duplicate destinations from Home.
- Added Delete to ordinary multi-file selection. Every selected regular file receives the same safety backup used by single-file deletion.
- Added Copy to multi-file selection and extended the transfer shelf to paste several files into another folder in one operation.
- Multi-select actions now use a bottom toolbar, with Select All and Done kept in the navigation bar.

For deliberate cache reclamation, Cache Cleaner remains the correct path because ordinary file deletion keeps safety copies. Batch operations stop on the first failure and report how many items completed, rather than silently claiming complete success.
