# iPixel-Files 0.9

## Full interface rebuild

- Made **iPixel Blue** the default visual system; **iPixel Lime** remains available.
- Added a text-free animated folder-stack splash screen.
- Rebuilt the dashboard with a stable hero, richer storage card and separated tool cards.
- Replaced raw path/diagnostic strips with readable current-location cards.
- Added animated folder-stack loading cards and progress indicators for long scans.
- Corrected the doubled rectangular search background under iOS 26 glass.
- Rebuilt credits as a compact About card with project and upstream links.
- Applied semantic light/dark colors to nested browsers, editors, menus and progress states.
