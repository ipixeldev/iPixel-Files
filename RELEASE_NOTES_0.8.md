# iPixel-Files 0.8

## Complete visual systems

- Added **iPixel Lime** and **Blue Files** interface styles.
- Both designs now apply across the dashboard, file browser, Apps, Cache Cleaner, backups, property-list editor, hex viewer, text/image viewer, Log, search, toolbars and nested menus.
- Added System, Light and Dark appearance controls from the dashboard paint-palette button.
- Replaced hard-coded dark-only colors with semantic palettes designed for readable contrast in both appearances.
- Added rounded themed list surfaces, selection states, progress indicators and search fields.

## New identity

- Added original pixel-art app artwork with a blue folder, data block and lime accent.
- Rebuilt all required iPhone and iPad icon renditions from the 1024 px master.

The filesystem access, backup safeguards and GPL-3.0-or-later upstream attribution remain unchanged.
